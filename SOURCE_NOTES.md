# Source reliability, attribution and limitations

1. NFL player stats / results: https://github.com/nflverse/nflverse-data/releases and https://nflreadr.nflverse.com/articles/nflverse_data_schedule.html. Credit nflverse for data from their automated release collections. The majority of nflverse releases have CC-BY licensing, but check the specific source for exceptions.
2. UFC historical primary: https://github.com/Greco1899/scrape_ufc_stats ; this is a third-party derived dataset that claims automated daily update from UFCStats. Treat as **unverified until current dated results are visible**.
3. UFC fallback: https://github.com/larissapavan/ufc-historical-fight-dataset ; historical source, unknown ongoing update cadence.
4. Original fight statistics: http://ufcstats.com/ ; this app does not scrape UFCStats directly and does not claim official UFC affiliation.
5. GitHub Pages and Actions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site ; scheduled workflow publishing is not real-time. GitHub Pages is a publicly served site.
6. No licensed sportsbook integration provided. Bet365 odds are typed by the user. All earnings, bankroll and probability figures are illustrative estimates.
